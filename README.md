# Testbook

Testbook is a beginner-friendly collaborative software development
platform designed primarily for college students.

## Purpose

The platform provides students with a structured environment to
practice professional software development workflows.

## Core Problems

- Difficulty understanding version control
- Overwriting project files
- Poor project version management
- Lack of code review practice
- Scattered collaboration
- Limited practical development workflow experience

## Core Features

- Authentication
- User profiles
- Repositories
- Files
- Commits
- Version history
- Branches
- Issues
- Pull Requests
- Code review
- Merge
- RBAC
