# TESTBOOK PROJECT CONTEXT

## Product

Testbook is a beginner-friendly collaborative software development
platform for college students.

## Primary Problems

1. Students struggle with version control.
2. Team members overwrite project files.
3. Students exchange ZIP files instead of maintaining versions.
4. Students rarely practice structured code review.
5. Bugs and discussions become scattered.
6. Students lack practical collaboration experience.

## Solution

Testbook provides:

Repository
↓
Files
↓
Commits
↓
Branches
↓
Pull Requests
↓
Code Review
↓
Merge

Additional:

Issues
RBAC
Activity tracking

## V1

Minor Project.

Duration:
2 months.

Goal:

A working end-to-end collaborative development workflow.

## V2

Major Project.

Duration:
3 additional months.

Goal:

Expand the platform with advanced collaboration and educational
features.

## Product Philosophy

Testbook should not blindly copy every feature of GitHub.

It should focus on solving the identified student problems with a
simpler and more understandable experience.
