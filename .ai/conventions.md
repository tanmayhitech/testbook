# TESTBOOK CODING CONVENTIONS

## TypeScript

Use strict TypeScript.

Avoid any.

Prefer explicit types.

## React

Use functional components.

Prefer reusable components.

Keep components focused.

## Backend

Routes
→ Controllers
→ Services
→ Prisma

## Naming

Components:
PascalCase

Functions:
camelCase

Variables:
camelCase

Constants:
UPPER_SNAKE_CASE when appropriate.

## UI

Use Tailwind CSS.

Testbook visual identity:

- Matte black
- Off-white
- Neutral gray
- Sage green

Avoid excessive purple and blue.
